ChatPro Beta estimates ChatGPT saved-history Pro usage in Tampermonkey. It supports subscription-anchored periods, server calibration, revision caching, automatic updates, reload restoration, pause/resume and 429 cooldown.

Use the `.user.js` asset to install/update the existing script. Keep one copy enabled. Full corresponding source is available in this tag; licensed AGPL-3.0-only. Original source notices are in THIRD_PARTY.md.

The panel supports Chinese, English and Spanish with browser-language detection, immediate manual selection and a saved preference. All languages share the same cache. README.es.md provides Spanish installation, quota, privacy and support guidance.

Pro $100 uses a shared 50/week preset. Pro $200 uses a shared 100/200 weekly preset with dated eligibility evidence and automatic expiry after October 29, 2026; missing evidence remains unknown before expiry. Pro $500 has a GPT-6 250/week preset. See docs/QUOTA_POLICY.md for official qualification dates, numeric-source limits and the local expiry convention. Presets and subscription-anchored periods are estimates, not verified server quotas for every account. Deleted/temporary history and branch/regeneration semantics can change totals.

Automated/offline tests are documented in VALIDATION.md. Live Tampermonkey verification is incomplete: release is Beta. Read PRIVACY.md before sharing any diagnostic file.
