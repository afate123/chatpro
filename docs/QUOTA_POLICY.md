# Allowance policy evidence

Checked October 8, 2026. The following separates source evidence from ChatPro's fallback choices.

## Pro $200 transition

[OpenAI Help Center](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers) specifies an active Pro $200 subscription at any point from September 22, 2026 through September 29 at 10 a.m. Pacific as the qualifying window. Previous allowances remain available through October 29 while Pro $200 is active. Cancellation and resubscription on the same account do not remove previously earned eligibility. The [September 29 release notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) also announce changing allowances and notification emails.

These official pages do not publish numerical 100/200 message limits. [An affected user's repost of the email](https://community.openai.com/t/pro-200-is-fine-please-don-t-improve-it/1402079) says GPT-6 Pro falls from 200 to 100 weekly messages starting October 30. This is a user repost, not an independently verified official email. ChatPro uses the numbers requested for this project.

The exact expiry instant is unpublished. ChatPro uses October 30 at 00:00 Pacific (2026-10-30T07:00:00Z) as its local calendar convention. It does not claim the server switches at that instant. Fresh server limits override presets. An old cached 200 cap is not carried past the transition without a fresh explicit server observation.

Current Pro $200 billing intervals overlapping the qualifying window establish local evidence. This evidence is saved under the verified account key so a later renewal/rejoin preserves it. A new monthly billing start outside that window cannot distinguish a new subscriber from a renewal; no guessed eligibility is created. Before the deadline, missing evidence yields an unknown cap unless the user selects a confirmed profile. After the deadline, the local fallback is 100, including previously selected old-qualification profiles. No additional history or billing endpoint is queried solely to discover eligibility.

## Sharing and other tiers

The project's requested policy is two-model shared 50/week for Pro $100 and shared 100/200/week for Pro $200. The [current model help page](https://help.openai.com/en/articles/20001354-gpt-6-and-other-models-in-chatgpt) describes a shared weekly allowance for Pro $100, but separate weekly/daily restrictions for Pro $200. Consequently the shared $200 aggregate is explicitly a local estimate policy, not a statement of verified official charging semantics.

Pro $500 uses the requested GPT-6 Pro 250/week preset. It does not invent a second-model or combined cap. Numeric fallback rules and billing-anchored seven-day periods are estimates; explicit server windows and caps take precedence.
