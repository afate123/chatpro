# ChatPro（Beta）

[English](README.md) · [Español](README.es.md) · [安装脚本](https://raw.githubusercontent.com/afate123/chatpro/main/dist/chatpro.user.js) · [更新记录](CHANGELOG.md) · [隐私说明](PRIVACY.md)

从 ChatGPT 云端保存的 Chat 历史估算 Pro 用量，支持安装前历史、其他设备已保存会话、增量缓存、刷新恢复和新回答自动更新。

这是非官方 Beta。订阅日期划分的是估算周期，未确认等于真实重置；服务器周期和上限优先。私有接口或页面变化可能影响功能。

![离线模拟数据，不是实际账号](docs/images/demo.png)

## 安装和升级

1. 安装浏览器的 Tampermonkey（油猴）。
2. 点击上方安装脚本，在油猴安装页确认。
3. 打开 chatgpt.com，点击 Pro 用量 → 开始自动扫描一次。

点击上方安装链接，或用本地 dist/chatpro.user.js 覆盖原脚本全部内容。只启用一份；常规升级保持脚本名称、namespace 和存储键不变，已有缓存保留。

打开或刷新会自动验证账号并恢复记录。完成扫描后持续监测新回答，页面可见时每 3 分钟补查；检查间至少 60 秒，检测到流式输出则推迟。浮层收起不停止更新；隐藏标签页不发起新检查。同步、限流与回答时长可能延迟统计。

界面支持中文、英文和西班牙语，自动模式按浏览器首选语言选择，其余语言回退英文。面板语言选择立即生效并跨刷新保存。三种语言共用同一脚本、缓存和统计；不调用翻译服务。日期按所选语言和本地时区显示，诊断中的字段与原始信息保持稳定。

## 套餐规则

| 档位 | 本地估算规则 |
|---|---|
| $100 | 两个 Pro 模型共享每周 50 次 |
| $200 | 两模型共享每周 100 或 200 次，按旧资格与期限自动判断 |
| $500 | GPT-6 Pro 每周 250 次，不编造另一模型或合计上限 |

这些数字以及 $200 的共享规则是本项目采用的估算规则，不表示当前账号服务器已经确认。[官方说明](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)规定：2026-09-22 至 09-29 上午 10 点（太平洋时间）曾有有效 $200 订阅，可保留旧资格至 10-29；同账号取消后重订仍可符合。公开帮助页未列出 200→100 数字，受影响用户有[转贴通知](https://community.openai.com/t/pro-200-is-fine-please-don-t-improve-it/1402079)。依据与限制见 [额度政策](docs/QUOTA_POLICY.md)。

自动模式发现订阅区间覆盖资格期，或本账号保存过符合资格的证据时，采用 200；近期续订起点无法排除旧资格，证据不足时仍显示待确认，可手动选择已确认资格。10-29 之后自动转 100，包括手动选择的旧资格。官方未给出到期的精确时刻，本地采用 10-30 太平洋时间零点，服务器新上限优先。

两个模型分项展示次数，共享额度只在合计行计算。默认用订阅起点重复划分每 7×24 小时；有已观察的服务器重置则优先校准。也可手动填写已知重置周期。订阅过期或必要字段缺失时不会伪造有效窗口。

## 统计和隐私

只统计成功完成的最终回答，按实际模型标签归属最近的用户提问；同一提问多次重新生成仍计一次，可能与服务器扣额口径不同。扫描普通与归档历史，排除已识别的 Work/Codex/临时聊天；删除的历史无法恢复。未分类或扫描未完成时，剩余未知。

每批最多 6 个详情、10 个历史请求、55 秒预算；请求串行至少间隔 2.5 秒，批间 60 秒自动继续。429 遵守冷却后续扫；普通错误或账号变化停止。暂停自动更新跨刷新保留，再次手动扫描完成可开启。

无遥测，无第三方数据后台；运行请求仅发往 chatgpt.com，油猴向公开 GitHub 地址检查更新。缓存仅留账号哈希、会话 ID、更新时间、模型、消息哈希、时间、周期与进度，不保存正文、标题、邮箱或令牌。诊断导出含账号哈希前缀和精确日期，公开前需检查脱敏。详见 PRIVACY.md。

## 开发和反馈

Node.js 22+，无 npm 依赖。运行 npm run build、npm test、npm run build:verify、npm run check。package.json 为唯一版本来源；release.config.json 配置仓库地址。发布步骤见 docs/PUBLISHING.md。

功能问题使用 Bug report 模板；不要上传 Cookie、令牌或聊天正文。安全问题见 SECURITY.md。自动测试和离线浏览器验证已执行，但真实油猴验收尚未全面完成，详见 VALIDATION.md 和 docs/LIVE_VALIDATION.md。
